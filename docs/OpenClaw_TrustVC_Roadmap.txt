OpenClaw Execution Blueprint
TrustVC Certificate Issuing Platform Transformation
Version 1.0

=== Phase 1: Stabilization & Security Foundation ===

Objective:
Establish a secure, production-ready TrustVC signing architecture.

Task 1.1 TrustVC Signing Validation
- Create standalone TrustVC signing test project
- Verify TrustVC lifecycle outside Next.js
- Standardize W3C VC payload format
- Eliminate mixed OpenAttestation and W3C payloads

Deliverables:
- Signed W3C VC
- Proof block generated
- Verification successful

Task 1.2 Move Signing Server-Side
- Create POST /api/issue
- Create POST /api/verify
- Remove browser-side signing
- Move TrustVC signing to backend services

Task 1.3 Key Vault Integration
- Azure Key Vault (preferred)
- Key retrieval service
- Signing proxy service
- Key rotation support

Task 1.4 Refactor TrustVC Layer
- Refactor trustvc.ts
- Refactor constants.ts
- Create TrustVCService
- Create DidService
- Create VerificationService
- Create IssuanceService
